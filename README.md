# SierraWorks brand assets

Only files in use. SVG is the master; PNGs are generated from it.

## Naming

`sierraworks-{asset}[-{background}][-{size}].{ext}`

- **asset:** `wordmark`, `mark`, `icon`, `favicon`
- **background:** `on-dark` (light letters) or `on-light` (dark letters) for wordmarks; `dark` or `light` for the tile of icons and favicons. The mark is amber and works on both.
- **size:** pixel width for logos (`-800`), pixel width and height for icons (`-512`). No size means SVG.

## Folders

| Folder | Files |
| --- | --- |
| `logos/svg/` | `sierraworks-wordmark-on-dark.svg`, `sierraworks-wordmark-on-light.svg`, `sierraworks-mark.svg` |
| `logos/png/` | Wordmarks at 400, 800, 1600 wide. Mark at 180, 360, 720 wide. Transparent background |
| `icons/svg/` | `sierraworks-icon-{dark,light}.svg`, `sierraworks-favicon-{dark,light}.svg` |
| `icons/png/` | Icon at 64, 180, 512, 1024. Favicon at 16, 32, 48, 180, 512. `favicon.ico` |
